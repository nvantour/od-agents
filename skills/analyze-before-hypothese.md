# Hypothese Schrijven

Gebruik altijd het volgende format bij het schrijven van een hypothese:

## Format
**Als** we [interventie/wijziging]
**Dan** verwachten we [verwacht effect op metric]
**Omdat** [gedragspsychologisch inzicht of data-onderbouwing]

## Voorbeeld
**Als** we social proof toevoegen aan de productpagina ("X mensen bekeken dit product")
**Dan** verwachten we een stijging in add-to-cart rate
**Omdat** mensen geneigd zijn het gedrag van anderen te volgen bij onzekerheid (social proof / Cialdini)

## Kwaliteitschecklist
Controleer elke hypothese op deze punten voordat je hem oplevert:
- [ ] Is de interventie concreet en uitvoerbaar?
- [ ] Is de metric meetbaar en gekoppeld aan een KPI?
- [ ] Is de onderbouwing gebaseerd op data, onderzoek, of een gedragsprincipe?
- [ ] Is de verwachte impact realistisch?
- [ ] Is de test technisch haalbaar?

## Werkwijze
1. Vraag Nino naar de context als die ontbreekt (welke pagina, welk probleem, welke data)
2. Formuleer de hypothese in het Als-Dan-Omdat format
3. Loop de checklist door
4. Geef suggesties voor verbetering als een punt niet voldoet
5. Stel relevante gedragsprincipes voor als onderbouwing (Cialdini, Kahneman, Fogg, etc.)
